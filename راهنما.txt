تجارت‌یار — راهنمای اجرای محلی
==============================

طراحی و توسعه: ستایش جعفری

۱) Python 3.12 را نصب کنید:
   https://www.python.org/downloads

۲) پوشه را Extract کنید.

۳) در همان پوشه ترمینال را باز و اجرا کنید:

   python -m pip install -r requirements.txt
   python app.py

۴) در مرورگر باز کنید:

   http://127.0.0.1:5000

اینترنت برای جست‌وجوی منابع عمومی لازم است.
برای توقف برنامه در ترمینال Ctrl+C را بزنید.
