TejaratYar Deployment Guide

راهنمای استقرار تجارت‌یار

طراحی و توسعه: ستایش جعفری

اجرای Colab

فایل TejaratYar.ipynb را باز و Runtime → Run all را اجرا کنید. لینک trycloudflare تا زمان روشن‌بودن Runtime فعال است.

اجرای Docker

docker build -t tejaratyar .
docker run --rm -p 7860:7860 tejaratyar

اجرای محلی

python -m pip install -r requirements.txt
python app.py

سپس http://127.0.0.1:5000 را باز کنید.

نکته امنیتی

فایل .env، کلید API، توکن و رمز را در مخزن عمومی قرار ندهید. فایل .env.example فقط نام تنظیمات غیرمحرمانه را نشان می‌دهد.
